01 Sobre mim

Sou a Stephany, desenvolvedora Full Stack e estudante de Ciência da Computação no Inteli. Gosto de interfaces bonitas, dados bem organizados e de entregar coisas que funcionam de verdade — do banco de dados até o último pixel.

Já construí app mobile em React Native com API em camadas e 210 testes automatizados, dashboard que mede o fluxo de times a partir do GitLab, automação com IA generativa e um simulador de vendas jogável para a Cielo.

Meu jeito de trabalhar: entender o problema antes de abrir o editor, modelar bem, escrever código legível e documentar para quem vem depois.
